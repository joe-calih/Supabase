# Soil

Soil is a responsive product website built with Next.js, TypeScript, Tailwind CSS, and shadcn-style UI components.

## What is included

- Homepage sections and responsive navigation
- Product pages for Database, Auth, Storage, Realtime, Edge Functions, and Compute
- Documentation experience at `/docs`
- Company, solution, customer, community, legal, and resource pages
- Supabase-style Postgres, authentication, storage, realtime, and developer messaging

## Development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000` in a browser.

## Validation

```bash
pnpm exec tsc --noEmit
pnpm lint
```
